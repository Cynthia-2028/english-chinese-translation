# 工作流与质检

接到一段文字到交出定稿，中间是一条有闸门的流水线，不是一次灵感发作。每个阶段只解决一类问题。混着做，就会在改标点时怀疑理解，在理解没到位时开始润色，改到第三遍分不清"这句是我译错"还是"这句原文就别扭"。

判断一篇译文能不能交，不看读起来顺不顺，看四件事：意思有没有丢、逻辑有没有断、语域对不对、机械层有没有脏。四件事分层过，一层一个判据。

主线只有一句：**先定用途，再定自由度；先求准，再求顺，最后求全。**

## 一、五个阶段总览

阶段 0 是闸门前的准备，1–5 是正文五步。每阶段有出口判据：不过就退回上一阶段。往前走一步的代价，永远大于退回去一步。

| 阶段 | 只解决一件事 | 产出 | 出口判据（不过就退回） | 典型失败 |
|---|---|---|---|---|
| **0 译前调查** | 这段文字为谁、为何、在哪儿用 | 调查表；术语专名清单；2–3 份平行文本 | 能一句话说清"读者是谁、读完后要做什么"；自由度已定档 | 拿到就译，译到一半发现是给外行看的科普，不是给同行的论文 |
| **1 理解** | 原文在说什么，谁在说，说到哪 | 逐段主旨；存疑清单；原文疑似错误清单 | 每段能用一句自己的话复述；每个代词能指回具体对象 | 成分都认识，整段意思说不出；把让步读成因果 |
| **2 表达** | 用译入语把这个意思重新写出来 | 粗译稿 → 脱离原文的改写稿 → 回核稿 | 三遍都走完；第二遍确实没看原文 | 只写一遍就交；在原文句法上换词 |
| **3 四层修改** | 分层清扫：准确、通顺、文体、机械 | 四层各有批注痕迹的改稿 | 四层都过；每层有实际改动或明确"无需改" | 一边对原文一边润色，两边都没做干净 |
| **4 质量控制** | 非语言层面的硬指标 | 打完勾的质控表 | 表上没有空格；空格处已写明原因 | 术语三个译法；数字单位混用；页码缺失 |
| **5 交付** | 说清取舍，留下痕迹 | 定稿 + 交付说明 + 修改记录 | 客户知道哪几处要他定；自己知道哪几处没把握 | 交完就完事，三个月后被问"这里为什么删了"答不出 |

### 1.1 时间怎么分（附三个不许跳的闸门）

| 文本情形 | 调查 | 理解 + 粗译 | 脱离原文改写 | 修改 + 质控 |
|---|---|---|---|---|
| 熟悉领域的信息类，格式固定 | 5% | 55% | 15% | 25% |
| 一般学术文本，术语需查 | 10% | 45% | 15% | 30% |
| 陌生专业、法律、医药 | 15% | 40% | 10% | 35% |
| 宣传、演讲、需重组的软文本 | 10% | 35% | 25% | 30% |

**任何文本，修改与质控不低于总时长的四分之一**，低于这个数，交出去的不是定稿。三个闸门：①调查表没填完，不许读第二遍原文（读法由用途决定，用途不明时读得越细，错得越深）；②理解没做完，不许落成完整句（句子一成型，人就会护着它）；③第二遍没走，不许进第四层（跳过的代价是所有句子停在"像原文"的状态，改标点改不掉）。

### 操作要点

1. 每阶段结束，用一句话写下"我现在能保证什么、还不能保证什么"。
2. 发现自己在同一段里既查词又改标点，停手，记位置，回到当前阶段该做的事。
3. **红线**：查词、落句、润色三段同时开工，是所有返工的起点。

## 二、阶段 0：译前调查

同样是"译一份报告"，给主管部门看和给媒体看，段落顺序、术语密度、是否保留套话，答案完全不同。**五分钟调查能省两小时返工。**

### 2.1 六件必须问清或查清的事

| # | 问什么 | 为什么必须问 | 问不到的后果 | 查不到时怎么办 |
|---|---|---|---|---|
| 1 | **文本类型与用途**：法律条文、学术论文、新闻通稿、产品说明，还是内部备忘？译出来做什么用？ | 类型决定自由度，用途决定"改写"是否合法 | 合同译成宣传腔，或宣传稿译成合同腔 | 按同类文本常规处理：法律从紧，报告从宽；交付说明写明推定依据 |
| 2 | **读者是谁**：同行、跨行学者、普通公众、审批部门？知识底子在哪一层？ | 读者决定显化程度与术语处理 | 给外行看的留满行话；给专家看的加一堆解释 | 按"最低共同知识"设定：知道本学科常识，不知道本文献的具体背景 |
| 3 | **发布场合**：期刊、会议手册、政府网站、微信推文、招标文件？ | 场合决定格式、称谓、篇幅、是否署名 | 格式全错，内容再好也不被接受 | 找该场合现成文本 2–3 份，照其骨架 |
| 4 | **长度与时限**：多少字、何时要、中间有无审校？ | 时限决定能走几遍，长度决定能否逐句查证 | 承诺了做不到的精度；前半段耗尽时间 | 明确告知"此时限内我只能做到哪一层"，把选择权交回客户 |
| 5 | **术语与专名清单**：有无既定译名、机构名、法规名？客户有无术语表？ | 术语一致是硬指标，事后统一成本极高 | 同一概念全篇三种译法；机构名不合官方译名 | 自建清单，首见定名，全篇锁定；无法确定的标"待确认" |
| 6 | **有无平行文本**：同类文本的译入语版本、官方译本、客户旧稿？ | 平行文本是最有效的文体与术语来源，有它就能"仿写"而非"创造" | 文体靠猜，术语靠造 | 至少找两份同类；找不到同类的，找同功能的（都是"征稿启事"或都是"方法节"） |

|---|---|
| 项目 / 日期 / 交稿 / 可用工时 | |
| 委托方与使用方 | |
| 用途（一句话）／读者读完后要做什么 | |
| 文本类型 | □法律合同 □学术论文 □研究报告 □新闻通稿 □产品说明 □宣传演讲 □邮件文书 |
| 主要功能 | □告知 □说服 □促成行动 □存档备查 |
| 读者 | □同行专家 □跨行学者 □普通公众 □审批部门；已知：＿＿ 不知：＿＿ |
| 场合与媒介／是否署名／长度与格式要求 | |

### 2.3 自由度档位：先定档，再动笔

档位定错，后面所有技巧都用错地方。定档看三件事：文本类型、用途、署名。

| 档 | 典型文本 | 可以动 | 不可以动 |
|---|---|---|---|
| **逐词档** | 合同、法规、专利权利要求、医药说明 | 语序、虚词；加注 | 信息项、情态强度、条件范围、术语 |
| **从紧档** | 学术论文、研究报告、官方文件 | 句法重组、长句切分、逻辑显化 | 论证结构、引文措辞、数据、论断强弱 |
| **常规档** | 新闻、一般说明、商务邮件 | 段内调序、合并重复、删套话 | 事实、数字、时间、人名机构名 |
| **可重组档** | 演讲稿、宣传册、公司简介 | 段落重排、删无关铺垫、抽象语具体化 | 核心信息、承诺性内容、署名者立场 |
| **可改写档** | 广告文案、旅游推介、口号 | 换喻体、重造句式、按译入语习惯重写 | 地点、时间、价格、规格、活动内容 |

一个反直觉的刻度：**广告、演讲比文学更"自由"，文学的自由只在句法层，不在语义层**——前者功能是效果，效果可重造；后者形式本身承担意义，改形式就是改作品。详见 `references/01-theory.md` 文本类型与自由度。

### 操作要点

1. 六件事里读者与用途最重要。其余四项可推定，这两项推错就全错。
2. 调查表不必给客户看，但自己必须填。填不出的格子就是后面会出事的地方。
3. **红线**：不声明就提高自由度是越界；术语表没建就译三千字以上，后面必然返工；客户催得再急也要问"给谁看、做什么用"。

## 三、阶段 1：理解

理解的目标不是"认识每个词"，是"知道这段话在做什么事"：谁在断言、谁在被反驳、哪句是让步、哪句是结论、哪个词是反讽。通读还要防一个陷阱：**读懂了句子，读丢了结构**——一段由"背景—让步—反驳—结论"四层构成，逐句都懂，合成一段可能读成"背景—结论"。自检办法：问"作者为什么写中间那两句，删掉行不行"；删掉还通，说明没读出它的功能。

### 3.1 通读一遍做什么（不查词，不落笔）

- **抓主旨**：读完每段用一句自己的话概括，不许用原文的词——概括不出的段落就是难点。
- **抓立场**：标出评价性词语、转折词、引语范围，弄清作者赞成谁、反对谁、替谁说话。
- **标不懂处**：术语、典故、专名、指代不明、逻辑跳跃、疑似笔误，全打记号，形成存疑清单。

### 3.2 逐句分析的三个动作

长句、逻辑复杂句、多修饰句必做；短句凭语感过。

| 动作 | 怎么做 | 一眼可辨的症状 |
|---|---|---|
| **找主谓** | 去掉从句、插入语、介词短语，剩下的才是骨架；确认主语的数、谓语的时态 | 译文主语缺失、中途换人、时态一段跳三次 |
| **切修饰** | 每个修饰成分用线连到被修饰词；连不上的就是歧义点 | 一个"的"字链超过三层；两个形容词抢一个名词 |
| **判逻辑** | 给每个小句标关系：因果 / 让步 / 条件 / 转折 / 并列 / 递进 / 反比 | 译文前后矛盾；"因为"接了一个不构成原因的分句 |

第三步最易错，也最难自查。三种高频误判：**把让步读成时间**——"在男女平等的今天，不平等依然存在"，这里的"在……今天"是"尽管"；**把递进读成转折**——"而"多数时候是"而且"；**把反比读成正比**——"随着经济增长而增减"字面像同向，实际可能相反，必须落到具体机制上验算。

### 3.3 什么时候必须停下来查（四种情况，不许猜）

| 类型 | 触发信号 | 查什么 | 查不到怎么办 |
|---|---|---|---|
| **术语** | 本领域有固定译名；或词典释义放进去读不通 | 专业词典、权威译本、平行文本中的用法 | 首见给"译名 + 原文"，全篇锁定，交付列入待确认 |
| **典故与互文** | 引号内短句、不完整引用、明显仿写；宗教、法律、文学出处 | 原文出处；该出处有无通行译本 | 重要的按原结构直译，让懂行读者能联想；不重要的可淡化，但不删承担意义的部分 |
| **文化专有项** | 制度名、职务名、俗语、饮食、地名别称 | 官方译名、同类文本惯例、有无既成译法 | 音译 + 类别词 + 简短解释，解释只给一次 |
| **疑似笔误** | 数字不合逻辑、年份矛盾、专名两种拼法、成分残缺 | 见 3.4 | 见 3.4 |

### 3.4 "原文可能写错了"的处理流程

1. **先怀疑自己**（顺序不能颠倒）：重读句子 → 查词义 → 查语法 → 查背景。
2. **再查外部证据**：平行文本、官方译本、同一作者的其他文本、数据本身能否自洽。
3. **分级判断**：能确定正确内容的是笔误；不能确定的存疑。
4. **提交疑问，不擅自改**：能确定则径改 + 留痕 + 交付说明；不能确定则原样译出 + 批注 + 请客户确认。
5. **实质内容一律不擅改**：事实、推理、立场表述，译出 + 注明 + 交作者或审校定夺。

| 错误类型 | 处置 | 谁有权决定 |
|---|---|---|
| 拼写、标点、明显漏字，答案唯一 | 直接改，交付说明 | 译者 |
| 数字年份矛盾，能由外部证据锁定 | 改，附证据与说明 | 译者 + 告知客户 |
| 数字年份矛盾，无法锁定 | 保留原数字，加注"原文如此，请核实" | 客户 / 作者 |
| 事实错误、推理错误、引文归属错；作者已联系不上 | 译出并加注，请审校定夺是否上报；或改并留痕 | 作者 / 审校 |

一条判据管总：**改的是"文字"还是"内容"？** 文字层面的笔误可改，内容层面的判断不能改。

### 操作要点

1. 通读阶段不许查词。查词会把注意力拉到局部，通读的任务是拿全局。
2. 存疑清单写成"位置 + 疑点 + 已查证据 + 待定问题"，不要只写"这里不懂"。
3. 判逻辑关系时先问"这两句能不能调换顺序"：能调换是并列，不能调换才有方向。
4. **红线**：不许因为"专业人士大概懂"就放过不懂处；不许悄悄改掉实质错误而不留痕——这不是帮忙，是替作者背书。

## 四、阶段 2：表达的三遍法

三遍各有任务，任务不许混。第一遍求准，第二遍求顺，第三遍求全。混着做，结果是每遍都在做三件事，每件都做不彻底。

| 遍次 | 只求 | 允许 | 禁止 | 时间占比 | 完成标志 |
|---|---|---|---|---|---|
| **一、粗译** | 意思不漏、关系不错 | 句子笨、重复、语序怪、标点乱 | 为顺而省信息；为美而加形容 | 40% | 每个原文信息项在译文里有落点 |
| **二、脱离原文改写** | 像译入语作者写的 | 拆句、并句、换语序、换主语、删冗余、改词性 | 对照原文；新增原文没有的判断 | 25% | 通读不必回头，读完知道每段在说什么 |
| **三、回原文核对** | 全、准、不错位 | 局部回调、补漏、改错 | 大段重写（说明第二遍做坏了） | 35% | 逐段能指认"这段对应原文哪段" |

### 4.1 第一遍：粗译

**贴着原文走，但只用译入语的骨架。** 长句先切，切完按原文顺序摆，不急着调。不会的表达先用笨说法占位，标记号，继续往前。质量判据只有一条：**信息项全不全**——数字、否定、条件、比较项、时态、情态，六类逐个落地。它们落地了，句子再丑也能救；它们丢了，句子再美也是废稿。允许留下的痕迹：`[?]` 表疑、`[待查]` 表术语、`[漏]` 表跳过的成分，这些记号是后面两遍的工单。

### 4.2 第二遍：脱离原文

**这一遍不能省。** 三条理由各自独立成立：

1. **原文句法会劫持译文句法。** 眼睛盯着原文，写出的句子会不自觉复制原文的语序、修饰位置、信息分布。这不是水平问题，是注意力问题。
2. **读不通的地方，只有不看原文时才暴露。** 对着原文读译文，大脑会自动用原文的意思填补空缺；脱离之后，空缺变成真正的空缺——读者遇到的正是这个空缺。
3. **改写需要"所有权"。** 文字只有被当成"自己写的"，才敢动结构。对着原文，人是抄写员；离开原文，人才是作者。

具体做法：把译文单独复制到新文件，原文不在视野内；一段一段读，读完停下问"这段在说什么，说清楚了吗"；只在两处停——读不懂（不是"我知道原文什么意思"，是"这段文字本身读不懂"）、读着别扭（要退回重读、要换气、要在心里翻译一次）；停下的地方重写整句，不动词，因为改写的最小单位是句子。

| 症状 | 动作 | 例 |
|---|---|---|
| 一句话读到第三个"的"才见中心词 | 长定语改小句，或中心词提前 | "对……的……的……的分析" → "分析了……，发现……" |
| 一句三个以上逗号且主语换过 | 断句，新句补主语 | 一逗到底 → 两三句，各有一主 |
| 每句都有"进行/作出/加以"；段末才知道要说什么 | 名词还原动词；结论句前移，铺垫降为从句 | "对数据进行了核对" → "核对了数据" |

禁区：**不许新增原文没有的信息。** 衔接用的连接词必须是原文隐含的关系；形容、评价、程度一律不许加。判断法：每个新增成分能否在原文字面找到锚点？找不到就删。

### 4.3 第三遍：回原文核对（只核对，不润色）

- [ ] 数字、百分比、年份、单位逐一比对
- [ ] 否定词次数与否定范围一致
- [ ] 条件与结果配对（范围没有扩大或缩小）；比较双方都在译文里，方向没有反
- [ ] 情态强度对应（must / may / should / shall 不串）
- [ ] 时态分界保住，过去没被压成现在
- [ ] 专名拼法、顺序、类别词与前文一致
- [ ] 每个代词能指回唯一对象
- [ ] 删减处删的是冗余，不是信息；增补处能指回原文某处
- [ ] 译文段数与原文不一致处有理由
- [ ] 标题与首段指同一件事

### 操作要点

1. 三遍之间间隔越长越好。粗译与第二遍之间隔一夜，强于连做三小时。第二遍换介质：打印出来读，或换到手机，眼睛的自动纠错会失效。
2. 顺序颠倒的代价：跳过第二遍，句子永远是原文的形状，通篇无语法错但每句都"像翻译"；先润色再补漏，补丁句与已润色的句子打架，一段两种文风。
3. **红线**：只写一遍就交，无论花多久都是草稿；第三遍发现大段要重写，不要硬改，退回第二遍。

## 五、阶段 3：四层修改（逐层清单）

四层分开过，一层一遍。**顺序不能变**：准确性在前，因为后三层都建立在"意思对了"之上；机械层在最后，因为它可穷尽、可机检，放前面是浪费。

### 5.1 第一层：准确性（对照原文；判据是"信息对不对"，不是"句子好不好"）

- [ ] 逐段并读，没有整句、整段遗漏
- [ ] 每处省略都能说明理由（冗余、重复、与主题无关），不是疏忽
- [ ] 每处增补都能指回原文字面或明确的隐含
- [ ] 主语补对：原文的施动者没有变成另一个人或一个抽象物
- [ ] 修饰关系没有错位（定语、状语挂错对象是最常见的硬错）
- [ ] 否定范围一致：否定的是词、短语，还是整句
- [ ] 比较项齐全（双方、维度、方向），条件与结果配对
- [ ] 时态与时间层次保住；情态强度对应（义务、许可、禁止、推测四级不串）
- [ ] 数字、百分比、年份、单位核对（含全半角、小数点、约数标记）
- [ ] 人名、地名、机构名、法规名与既定译名一致；引文与原文一致、归属正确
- [ ] 原文疑似错误处已按流程处理并留痕；逻辑自洽（译文内部、译文与常识、译文与背景）

### 5.2 第二层：通顺（脱离原文通读；判据是"像不像译入语作者写的"）

- [ ] 每段能用一句话说出主旨；说不出就重组
- [ ] 段落顺序符合译入语推进习惯（先总后分、先重后轻、先近后远）
- [ ] 段内句子顺序可调处，逻辑仍然成立
- [ ] 每句主语明确（连续三句无主语或同一主语都要处理）；代词指代清楚
- [ ] 长定语已拆：一个中心词前超过三层修饰必须拆；一句不超过三个信息点
- [ ] 连接词分级投放；一段内同型不超过两次
- [ ] 无近距离重复（同词、同结构、同句式连用）；无不言自喻的冗余
- [ ] 无名词化膨胀："进行/作出/加以/对……的……"可还原为动词
- [ ] 无欧化句：被动连用、"被"字滥用、"关于/对于/在……方面"开头
- [ ] 无悬垂修饰：分词、介词短语的逻辑主语与主句主语一致
- [ ] 朗读一遍，没有换气困难、拗口、绕回原处；语域统一，不出现文言与口语混搭

### 5.3 第三层：文体（对照 2–3 份同类文本；判据是"像不像这个场合该有的文字"，详见 `references/07-register.md`）

- [ ] 体裁格式正确：书信的日期与称谓、论文摘要的结构、合同的条款层级、公文的抬头落款
- [ ] 称谓与敬语到位：职称、学位、职务的正确用法；不认识收件人怎么称呼
- [ ] 开头该开门见山：铺垫、时令语、感谢语在该体裁里是否保留
- [ ] 结尾有固定格式：签名、职务、联系方式、日期占位
- [ ] 夸饰克制：不可验证的形容词、绝对化表述、自夸定语已删或降调
- [ ] 术语密度与句长分布合体：科普要降、广告要短、论文要稳、法律要长而清
- [ ] 少用生僻缩写：首见展开，不必要的还原
- [ ] 隐喻与成语合体：该体裁是否接受比喻，比喻是否与语域冲突
- [ ] 引语方式合体：直接引语与间接引语的选择，引号与标点配合
- [ ] 格式元素齐全：编号体系、层级符号、图表标题、注释体例
- [ ] 标题与正文一致：标题承诺的内容，正文兑现了

### 5.4 第四层：格式与机械错误（可机检，必须单独一遍，放最后）

- [ ] 标点体系：中文不用英文半角标点；英文不用全角标点、不用顿号
- [ ] 标点空格：英文标点前无空格、后一空格；中文标点前后无空格
- [ ] 引号与括号配对：中英不混用，嵌套层级正确，句末标点位置正确
- [ ] 大小写：标题实词规则统一，专名首字母正确
- [ ] 专名拼法：中国人名地名用拼音，姓与名分段正确，不拆三截
- [ ] 音译词体例：斜体、大小写、连字符全篇一致
- [ ] 拼写：工具过一遍再人眼过一遍（工具会放过专名与术语）
- [ ] 语法：主谓一致、单复数、冠词、时态呼应、介词搭配
- [ ] 数字与单位体例：全半角、千分位、小数位统一；换算前后一致
- [ ] 编号与列表：层级符号统一，末项 and/or 与项数匹配
- [ ] 交叉引用：图表号、章节号、页码、附录号指向存在的对象

### 操作要点

1. 每层开始时先声明"这一层只看什么"，写在纸上，防跑偏。每层结束统计改动数：某层零改动，要么真干净，要么没做。
2. 四层的时间分配约为 30% / 20% / 10% / 10%，余下 30% 是查证与回问，不算在四层里。
3. 四层做完隔一天从头读一遍，通常还能找出五到十处。
4. **红线**：不许在同一遍里既对原文又改文风；机械层的错不算小错，它是专业度的第一眼判据。

## 六、阶段 4：质量控制打勾表

四层修改管"文字"，这一节管"非语言层面"：单看每项都小，错一处就足以让整篇显得不专业。

### 6.1 术语一致

- [ ] 同一概念全篇同一译名（含标题、摘要、图表说明、注释）
- [ ] 同一语法词在同一文本内用法一致（法律文本 shall / must / may 不混）
- [ ] 术语表已建，含"原文—译名—首见位置—备注"；无对应时用"译名 + 原文/解释"，只解释一次
- [ ] 关键词与摘要、标题一致；摘要改写后关键词已同步重拟

### 6.2 数字与单位

- [ ] 百分号、温度符号、货币符号的全半角统一
- [ ] 数字与单位间空格、数字内部千分位统一；约数标记未丢
- [ ] 量纲换算自洽（同一对象的长度、面积、重量全文只有一套数）；精度取舍全篇统一

### 6.3 专名

- [ ] 人名：姓与名顺序、分段、拼法统一；海外华人从其本人拼法
- [ ] 地名：行政区划层级完整；少数民族语用罗马化转写；必要时补语义
- [ ] 机构名、法规名、品牌名：采用官方或既定译名，不自行创译；首见全称，后文简称

### 6.4 引文与页码

- [ ] 引文尽量找原文；找不到时改为间接引语并说明
- [ ] 引文归属已核实（谁说的、在哪说的、有没有被误传）
- [ ] 直接引语与间接引语边界清楚；页码、版本、网址、访问日期齐全，转引标明"转引自"

### 6.5 标题、图表与交叉引用

- [ ] 标题与首段指同一件事；标题无歧义词、无不可解析的名词串
- [ ] 图表标题编号连续，与正文引用号一致；图表内文字、单位、图例已译
- [ ] "上述/该/此/前者/后者"都有明确先行语
- [ ] 章节号、条款号、附录号、脚注号指向存在的对象；条款援引关系正确

### 6.6 日期与体例

- [ ] 日期格式全篇统一（年月日顺序、分隔符、是否补零）；时间表达统一
- [ ] 度量衡采用读者习惯单位或原文单位 + 换算；注释体例、参考文献格式统一；页眉页脚与文件属性已检查
- [ ] 版式统一：段首缩进或段间距、字体字号、行距与表格线，与交付要求一致

### 操作要点

1. 这张表交稿前打印出来，用笔打勾。电子打勾容易漏行；不许留空格，填"不适用"或"已与客户确认"。
2. 术语与数字的错客户一眼能看出；文体与逻辑的错客户未必看出，同行看得出。两类都要管。

## 七、阶段 5：交付与留痕

交付不是发文件，是交接。客户拿到的不只是译文，还有"哪几处要他决定"。

### 7.1 交付说明写四件事（每条都要能被不懂原文的人读懂）

| 项 | 写什么 | 写法 |
|---|---|---|
| **取舍** | 删了什么、合并了什么、调了什么顺序 | 说位置与理由，不说"为了通顺"。"第三段疫情背景移到文末，因为英语邀请函先给会议信息" |
| **疑难** | 哪几处没把握，几种译法各有什么代价 | 给方案，不给问号。"原文此处可作两种切分，我按 A 处理；若确认是 B，第二段需重写" |
| **待确认** | 需要客户提供或决定的信息 | 列清单标位置。"日期、对方地址邮编、签字人职务，见文中方括号" |
| **原文问题** | 疑似笔误、事实矛盾、引文归属错误 | 附证据与处理方式。"原文 1997 与 1998 前后矛盾，已按 1999 处理，请作者核对" |

### 7.2 留痕

留痕不是自证清白，是让三个月后的自己或接手的同事能还原判断。

| 留什么 | 怎么留 | 留在哪 |
|---|---|---|
| 改动与原文疑似错误 | 批注：原译 / 改译 / 理由 / 证据 | 译文对应位置 |
| 术语决定 | 术语表：原文 / 译名 / 依据 / 首见位置 | 单独文件，随稿交付 |
| 待确认项与版本 | 方括号占位写明要求；文件名带日期与版本号，不覆盖旧版 | 译文内 / 项目文件夹 |

### 操作要点

1. 交付说明控制在半页内。超过半页，说明前面某阶段没做好。
2. 每条"待确认"都给默认处理方案，让客户可以只回"同意"；交付后再读开头和结尾，这两处客户最先看。
3. **红线**：不许把没做完的部分混在定稿里（占位符、`[?]`、`TODO` 必须清零或列入清单）；不许隐瞒删减；不许对没把握的地方保持沉默——沉默等于担保。

## 八、错误复盘与个人清单模板

误译不会因为"下次注意"而减少。能减少的只有一种：**把错误变成可识别的触发条件**——"注意形近词"是愿望，"看到 `motionless / emotionless` 同段出现，逐个查词性"才是动作。归类看三层：错在理解、表达还是核查（决定补哪个动作），由什么触发（决定设什么检查点），后果多重——致命、明显、轻微（决定优先级）。三层里"触发条件"最有用，它把抽象的自责变成具体动作。

### 8.1 错误清单模板

| 错误类型 | 触发条件 | 下次的预防动作 |
|---|---|---|
| 词义取首义 | 一词多义，首义读得通 | 落笔前查完整释义，不只查首义 |
| 形近词混淆 | motionless / emotionless 同段 | 同段出现形近词，逐个标词性 |
| 否定范围错 | `not...because` / `no...but` | 译完圈出否定词，画范围线 |
| 比较项缺失 | `more than` / `as...as` | 检查比较双方是否同现 |
| 让步读成因果 | "在……的今天""虽说" | 遇到时间或条件框架语，先问是否让步 |
| 修饰语挂错 | 连续两个以上 `with` / `of` | 每个介词短语用线连到被修饰词 |
| 代词指代不明 | `it` / `this` / `they` 跨句 | 每三句回溯一次，指不回就换名词 |
| 时态压平 | 叙事段过去与现在交替 | 段内标时态，段与段之间不断层 |
| 数字单位失配 | 原文两处同一数据 | 建数据表，全文只剩一套数 |
| 专名不一致 | 同一人名地名多次出现 | 首见建条目，后文只查表 |
| 术语漂移 | 同一概念三种说法 | 译前建表，译后搜关键词 |
| 漏译／增译越界 | 长句、括号、插入语；为通顺补成分 | 逐段比对；每个新增成分回指原文 |
| 套话未删 | 宣传腔形容词堆叠 | 问"删掉后信息少没少" |

### 操作要点

1. **每篇译完记三条。** 只记三条，多了记不住，挑后果最重的。
2. **同类错误出现三次，升级为检查点**，写进打勾表或开工前默念清单。
3. **写具体到词、到句式**，复盘当天做。"逻辑没理清"没有用；"`not...because` 先判否定范围"有用。别人指出的错误和自己的错误分开记——前者往往是盲区，价值更高。

## 九、时间估计与脱困动作

### 9.1 单位产出速度（区间，不给精确数字）

| 文本情形 | 每小时产出（译入语字数） | 主要影响因素 |
|---|---|---|
| 本专业论文、熟悉领域报告 | 500–700 | 术语熟、句式熟、格式固定 |
| 新闻、说明、商务文书 | 400–600 | 句子短、信息密度低 |
| 一般学术文本，术语需查 | 300–450 | 每段有一两个概念要查 |
| 宣传、演讲、需重组的软文本 | 200–350 | 需重排结构、重造句式 |
| 陌生专业、法律、医药、招标 | 150–250 | 每句要查证，术语不能自造 |
| 文学性文本、需保留形式的 | 100–200 | 一词多义、形式承担意义，反复掂量 |

三条换算：这是**粗译速度**，加上三遍修改与质控，总时长约为粗译的 1.8–2.2 倍；第一次做某类文本按区间下限的 70% 估；有完整平行文本与术语表，速度提高 20%–30%，没有则按上限的 80% 估。

### 9.2 卡住时的三个动作

一句话改了很多遍还是不对、一个词查半小时还在原地、读自己的译文像读别人的错稿——继续坐着没用，换动作。

| 动作 | 具体做法 | 适用于 | 不适用于 |
|---|---|---|---|
| **离开原文，改读译文** | 把这句单独拿出来，只看译文，问"如果我是读者，这句什么意思"，写下答案，再回原文比对 | 读不通、逻辑跳跃、改多遍仍别扭 | 怀疑术语译错、怀疑漏信息 |
| **查平行文本** | 找 2–3 份同类文本，只看同一功能怎么表达（怎么开头、怎么列举、怎么下结论），抄结构不抄句子 | 文体不会、格式不会、套话不会转 | 事实性疑难、专名核实 |
| **隔时重看** | 至少隔一夜；换介质（打印、手机、投屏）；或朗读一遍 | 全部情形，尤其"读太多遍已麻木" | 急稿、当天交付 |

三个动作背后是同一条原理：**卡住多半不是能力不够，是注意力锁死在一条路上。** 两个应急手段：**降级处理**——难句拆成两句短句，拆完常常发现难点消失；**标记跳过**——`[?]` 标上，往前译三百字再回来。

### 操作要点

1. 估时按"最慢的一段 × 全文段数"算，比按平均数算准。查证时间单独记账，查证占比是判断文本难度最诚实的指标。
2. 卡住超过二十分钟必须换动作。坐着硬想，二十分钟后还是二十分钟。
3. 出现三个信号就该加时间并告知客户，不要熬夜硬赶：前 20% 篇幅用掉 40% 时间且剩余难度不低于前面；查证超过翻译时间的一半；已经动了"跳过核对"的念头。

## 十、改稿与协作

### 10.1 给别人改稿 vs 自己改稿

| 维度 | 自己改 | 给别人改 |
|---|---|---|
| 最大障碍 | 记得自己为什么这么译，看不见别的可能 | 不知对方为什么这么译，容易改成自己的风格 |
| 首要动作 | 制造陌生感：隔时、换介质、朗读 | 先读懂对方思路，再判断对错 |
| 改动尺度与权限 | 可以大改，自己承担 | 只改错，不改风格；能不改就不改，必改处给理由 |
| 判据 | "这是不是我想说的" | "这是不是原文说的" + "这是不是译入语能接受的" |
| 常见失误 | 只改词不改句；越改越像自己的旧稿 | 把偏好当错误；改对了但伤了对方积极性 |

别人的稿子，**改动力度与文本重要性成反比的地方恰恰要小心**：越不重要的文本越容易改过头；越重要的文本（合同、论文）越要只动该动的地方。

### 10.2 批注怎么写（忌反问句、忌"建议再斟酌"、忌一处说三件事）

三段式，缺一段不成立：**指出问题 → 给出方案 → 说明理由。** 不合格的批注是"这句译得不对"。合格的写全三段："问题：这个 which 从句被译成前置定语，读者读到第三个'的'才知道中心词是'要求'。方案：拆成两句——'该法于 2019 年生效。它要求企业每年披露一次数据。'理由：原文的 which 从句是非限定性的，起补充说明作用；译成定语会被读成'只有部分要求'。"

| 类型 | 写法 | 例 |
|---|---|---|
| **硬错**（误译、漏译、数字错） | 直接改 + 一句话理由 | "原文是 15%，不是 50%，已改。" |
| **软错**（不通顺、语域不合） | 给方案，允许对方不改 | "建议拆成两句，理由是……；若保留原句，至少把'进行'删掉。" |
| **偏好**（两种都对） | 只提，不改 | "我倾向'核查'而非'检查'，因为前文用'核查'；不改也可。" |

### 10.3 收到反馈怎么处理

先分类，再回应。混在一起处理，会把偏好当错误改掉，也会把错误当偏好放过。

| 反馈类型 | 识别信号 | 处理 |
|---|---|---|
| **硬错** | 指出具体位置与错法（数字、否定、人名、术语） | 立即核实，改，致谢，不解释 |
| **理解分歧** | 说"原文不是这个意思"，但给不出依据 | 回原文重读，列证据；有依据就改，没依据说明自己的依据 |
| **语感/风格偏好** | "读着别扭""太口语""太文" | 对照体裁与读者：是普遍习惯就改，否则保留并说明 |
| **格式体例／越界要求** | 标点、空格、编号、称谓；要求改内容、立场、数据 | 体例按客户改，不辩论；越界则说明边界，请客户书面确认并写入交付说明 |

三条原则：**先确认再讨论**——"我看到了，第 3 段第 2 句，我先核一下原文"，这句话能消掉一半冲突；**用证据不用资格**——不说"我译了十年"，说"原文是 `not unless`，否定范围是整句"；**该坚持的坚持**——对方要求把误译改回去以符合他的印象时，给依据，说不通则记录在交付说明里。

### 操作要点

1. 给别人改稿，第一遍只读不改。读完再动手，避免把全文改成自己的句子。批注写在问题旁边，不要汇总在文末——汇总的批注，改稿的人要来回翻。
2. 协作的现实版本是：一人初稿、一到两人审校、客户再把关。**初稿阶段就把疑难标出来**，比审校阶段辩解有效——批注写在当时，理由还是热的。最终稿与你的稿子差别很大不等于失职，但差别处要能解释。
3. **红线**：不许把风格偏好写成硬错；不许没读完全文就改别人的稿子；不许默默接受一个你认为错误的改动——要么说服，要么留痕。
